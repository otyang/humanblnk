# Security policy

humanblnk moves money, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on
[github.com/otyang/humanblnk](https://github.com/otyang/humanblnk/security/advisories/new).

Include what an attacker could do, the steps to reproduce, and the versions of
humanblnk and Blnk Core involved. You'll get an acknowledgement within a few
days and credit in the release notes if you'd like it.

## Supported versions

Fixes are made on the latest release. Before v1.0.0, upgrade to the newest
minor version to receive security fixes.

## Scope

In scope: this library (`ledger`, `blnk`, `ledgertest`). Vulnerabilities in
Blnk Core itself should go to the Blnk project.
